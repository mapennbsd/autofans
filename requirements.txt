# Python drivers for dawg (Raspberry Pi 3 B, Debian 13 trixie, Python 3.13,
# arm64), pinned with PyPI's sha256 for each wheel.  Install into a venv made
# with --system-site-packages:
#
#   PIP_CONFIG_FILE=/dev/null /opt/autofans/.venv/bin/pip install --no-deps \
#       --require-hashes --only-binary :all: \
#       --index-url https://pypi.org/simple -r requirements.txt
#
# --no-deps on purpose.  On arm64, Blinka also requires RPi.GPIO, lgpio,
# rpi_ws281x and Adafruit-Blinka-Raspberry-Pi5-Neopixel, which are source-only
# on PyPI and would compile.  This program uses only board.I2C(), and Blinka
# imports RPi.GPIO for every Pi 3 pin, so the RPi.GPIO module comes from apt
# instead: python3-rpi-lgpio, a shim over python3-lgpio.  `pip check` will
# report those four as missing; that is expected.
#
# PIP_CONFIG_FILE=/dev/null drops Pi OS's piwheels extra index: piwheels
# rebuilds wheels, so their hashes would not match these.
#

# API.  To update, resolve in a plain venv (no --system-site-packages),
